A tag <ol> possuí o parâmetro type onde configuramos o tipo de marcador de lista atual. As opções de valores para esse parâmetro são:
1 - valor padrão cria listas númeradas...
A - cria listas alfabéticas em maiusculas...
a - cria listas alfabéticas em minúsculas...
I - cria listas em algarismos romanos em maiusculas...
i - cria listas em algarismos romanos em minúsculas...

Você também pode indicar o início da contagem usando o parâmetro start por exemplo a tag <ol type="I" start ="5"> vai gerar itens númerados como V,VI,VII etc...
Já as listas desordenadas ou de marcadore,que são aquelas que a ordem dos itens não influenciará no significado da lista. Ela é apenas uma ótima maneira de organizar os itens que não apresentam uma classificação necessariamente, ela é caracterizada pela tag <ul> e também usa <li> para seus itens.
O marcador padrão da <ul> são as bolinhas pretas totalmente preenchida mas também é possível alterar isso usando a propriedade type na <ul> com os seguintes valores:

 Disc - Padrão, bola preta totalmente pintada.
 Circle - Uma bola com uma borda preta sem preenchimento.
 square - Um pequeno quadrado preto totalmente pintado

Ligações, estas são feitas por meio dos hyperlinks, para criar um hyper link devemos criar âncoras utilizando a tag <a> o principal atributo desta tag é o href="", que cria uma referência hipertexto.Vamos ver um exemplo simples:
    <h1>Vamos Criar um link</h1>
    <a href="https://www.youtube.com/watch?v=X5WjKpilICM&pp=ygUcbWVtZSBkbyBjYXJhIGNhbnRhbmRvIGluZ2xlcw%3D%3D">Clique Aqui</a>

Outro atributo muito útil da tag âncora é o hreflang, que permite indicar qual é o idioma principal do site para onde o link está desviando o fluxo de navegação. Isso vai permitir avisar o navegador e o software de tradução como lidar caso o visitante opte por traduzir automaticamente os conteúdos.
Por padrão, sempre que o visitante clicar no hyperlink o site destino abre na mesma janela do site que continha esse link. Ou seja, o conteúdo anterior vai deixar de ser exibido para mostrar o novo conteúdo.
Esse é um comportamento desejado quando o visitante vai continuar a visitar nosso site, apenas mudando de um documento para outro. Mas e quando um clique leva ao visitante para outro site e provavelmente ele nunca mais voltará para o nosso site?
Para poder controlar onde o site destino irá abrir, podemos usar o atributo "Target" que suporta os seguintes valores:

_blank vai abrir o link em uma nova janela em branco.
_self vai abrir o link na janela ou frame atual(padrão).
_top vai desfazer todos os frames e abrir o destino no navegador completo. 
_parent similar ao uso do _top em uma referência à uma janela mãe.
nome-do-frame caso esteja usando frames, indicar o nome da janela a abrir.

como o uso dos frames é uma técnica quase me desuso, vamos nos basear apenas nas duas primeiras opções _blank e _self.
   <a href="pagina2.html" target="_self">continuar navegando no site</a>
   <a href="https://www.w3schools.com/sql/sql_datatypes.asp" target="_blank">Abrir o W3school em uma nova janela</a>

Existe um recurso bem interessante para links que é indicar qual é a natureza do destino usando o atributo rel. Esse atributo aceita vários valores entre eles:
next indica que o link é para a próxima parte do documento atual.
prev indica que o link é para a parte anterior do documento atual.
author indica que é um link para o site do autor do artigo atual.
external indica que é um link para outro site que não faz parte do site atual.
nofollow indica que é um link para um site não endossado, como um link pago.
    <a href="pagina2.html" target="_selft" rel="next">continuar navegando no site</a>

    <a href="https://www.w3schools.com/sql/sql_datatypes.asp" hreflang="en" target="_blank" rel="external">abrir este site em uma nova janela</a>

No código anterior o primeiro link é o que chamamos de link local ou link interno, já que ele leva o visitante a outra página detro do nosso site. Note que não é necessário nem indicar a URL completa nesses casos.

Já o segundo link vai nos levar para um outro site, o que chamamos de link externo, nesses casos, devemos indicar a URL completa, incluindo o protocolo http:// ou https:// e o caminho leva à uma página específica, se for necessário.

Para linkar páginas é importante usar os atalho CTRL+SPACE e também usar ./ e ../ para retornar de páginas dentro de pastas diferentes.

<a href="arquivos/meulivro.pdf" download="meulivro.pdf" type="application/pdf">Baixe Aqui O PDF Do Meu Livro</a>

Imagens, Videos e Áudios
Sites devem ser responsivos para todas as plataformas e para isso fucnionar deve-se tornar ele responsivo e o primeiro passo para isso é aprender a utilizar a tag source e a tag picture.

Para esse exemplo, criamos as três imagens ao lado, a menor tem 300x300px, a média tem 700x700px e a maior tem 1000x1000px, usamos o programa gimp, que é um editor de imagens 100% gratuito, essas imagens serão carregadas pelo navegador de acordo com o tamanho da janela atual. Para isso, criamos o seguinte código base:

    <picture>
        <source media="(max-with: 1050px)" srcset="wolfs-700.png" type="image/png">
        <img src="wolfs-1000.png" alt="A Imagem Flexível Funciona">
    </picture>
Note que a tag source possui 3 atributos:

type vai indicar o media type da imagem que usamos

srcset vai configurar o nome da imagem que será carregada quando o tamanho indicado for atingido.

media indica o tamanho maximo a ser considerado para carregar a imagem indicada no atributo srcset.

É sempre bom colocar um valor ligeiramente maior na max-width para resultados mais interessantes.
Após colocar mais um source media o site fica ainda mais responsivos.

    <picture>
        <source media="(max-width:740px)" srcset="wolfs-300.png" type="image/png">
        <source media="(max-width: 1050px)" srcset="wolfs-700.png" type="image/png">
        <img src="wolfs-1000.png" alt="A Imagem Flexível Funciona">
    </picture>

É importante que exista uma ordem entre os <source>, e nessa configuração os itens mais acima sejam os menores tamanhos para max-width e que os seguintes sejam os maiores, de forma crescente, O último item dentro de <pictures> deve ser a imagem padrão.

Vamos falar sobre áudio:
Com o HTML 5, veio também a facilidade em compartilhar áudio nos nossos sites sem depender necessariamente de JS ou plugins extras. A partir de agora, bas uma tag <audio> e alguns source para fazer seu site ser capaz de tocar qualquer áudio.
Vamos analisar os principais atributos de uma tag áudio antes de mais nada:

o atributo preload indica se o áudio será pré-carregado ou não aceita três valores:
	     metadata vai carregar apenas informações sobre o arquivo (tamanho,tempo,informações de direitos, etc...)
	     none não vai carregar absolutamente nada até que o usuário clique no botão play ou um script inicie a reprodução.
	     auto(padrão) vai carregar o arquivo de áudio inteiro assim que a página for carregada, mesmo que o usuário nunca aperte o play.

O atributo controls vai apresentar o player na tela. Caso não seja colocado na tag <audio>,o controle será transparente e o usuário não poderá interagir com ele.
O atributo autoplay, quando inserido, vai iniciar a reprodução do áudio assim que a página for carregada.
O atributo loop vai fazer com que o áudio seja repetido eternamente assim que terminar sua reprodução.

Dentro da tag <audio>, adicionamos vários <source> com formatos diferentes do mesmo áudio. Coloque na parte de cima o seu formato favorito. Os demais só serão carregados caso o de cima falhe. caso todos falhem, criamos um parágrafo que permite download do arquivo mp3 para ouvir no player padrão do dispositivo.

E os Videos?
Para inserir um vídeo em nosso site, podemos utilizar a nova tag <video> do html 5, caso o arquivo esteja hospedado no nosso próprio servidor.
Antes de mais nada, vamos criar a tag <video> e configurar alguns atributos importantes.

    <h2>video</h2>
    <video width="300" poster="thumb.jpg" controls autoplay>
        <source src="videoteste.mp4" type="video/mp4">
        <p>Infelizmente seu navegador não conseguiu carregar o 	video</p>
    </video>

width vai indicar a largura que o video vai ter na tela por exemplo "600px".
poster configura uma imagem que vai aparecer como uma capa, enquanto o visitante não aperta o play do vídeo.
controls vai configurar se os controles do video vão aparecer na parte inferior da midia. Por razão, os controles não aparecerão, mas basta colocar a palavra controls na tag videos.
autoplay diz para o navegador se o video vai começar a tocar automaticamente, assim que a página for carregada.
Hospedar seus próprios videos pode ser caro pois o tráfego aumenta para cada video reproduzido por cada usuário. É preciso tomar cuidado ao guardar nossos videos.
E como contornar esse problema? Simples usando Youtube ou Vimeo para hospedar seus videos. Youtube tem servidores ultra rápidos porém pode ser uma dor de cabeça pois a ideia do youtube é deixar todos seus videos públicos ou disponíveis, o que pode ser uma dor de cabeça para conteúdos privados.
Vimeo resolve o problema anterior, Ele permite limitar quem vai poder ver seus vídeos, o que é especialmente vantajoso para quem quer criar produtos em forma de vídeo, como desvantagem é que ele é pago por uma taxa anual e seus algoritmos não são tão rápidos  quanto os do youtube.
Para incorporar videos que subiu no youtube ou vimeo existem recursos que te dão o código pronto no HTML5.
No youtube abra o video e clique em compartilhar e escolha o item incorporar.
O código HTML personalizado vai aparecer em uma nova janela um exemplo de código seria:
    <h2>Teste Video Youtube:</h2>
    <iframe width="560" height="315" src="https://www.youtube.com/embed/7PcMlAZJVJQ?si=_HfaqvKMfmA-JEgY" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen></iframe>

Utilizando CSS internal style:
Para aplicar estilos de forma mais dinâmica e prática, podemos adicionar uma tag <style> dentro do <head> no nosso HTML, tente isso:
<!DOCTYPE html>
<html lang="pt-br">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Usando CSS</title>
    <style>
        body{
            font-family: Arial, Helvetica, sans-serif;
            background-color: lightcyan;
            color: blue;
        }
        h1{
            color: green;
        }
    </style>
</head>

Lembre-se as configurações pontuais sempre vão prevalecer sobre as configurações gerais. volte ao código e romava todas as configurações de style dentro da tag body e H1.
A técnica mais versátil seria o css external style, manter as folhas de estilo fora do código HTML, além de uma maior organização faz com que tudo seja reaproveitado da maneira mais eficiente nas outras páginas do nosso site, para isso, utilizamos a tag <link> especialmente configurada para trabalhar com aquivos externos de estilo. Essa tag deve ser colocada dentro da área <head> do seu html.

    <link rel="stylesheet" href="style.css">

A linha linha com o <link> pode estar em qualquer linha, contanto que seja dentro do <head>, uma boa opção é sempre colocar ela abaixo do <title>.
Um bom atalho é colocar link CSS e depois ir até a referencia e colocar ou mouse acima dela, logo depois pressione CTRL+CLIQUE e o próprio VSCode vai perguntar se você quer que ele crie a pasta por você.

Importância das cores,ter cores harmoniozas em seu site ajudam na retenção dos usuários e venda de produtos.
Podemos gerar gradientes e aplicarmos a componentes visuais usando as folhas de estilo. Vamos usar um exemplo simples no nosso exercício atual. vá até o body e crie uma declração do nosso seletor body.

body{ font-family: Arial, Helvetica, sans-serif;
    background-image: linear-gradient(90deg, yellow, red);
    color: black;
}

Pode parecer esquisito no início, mas um gradiente é considerado pelo navegador como se fosse uma imagem, por isso usamos a propriedade background image na declaração CSS. Seletores personalizados em css:
Agora que nós já passamos pelos elementos mais importantes no design, que são cores e fontes, vamos falar um pouco sobre formatações especiais que vão permitir organizar esses conteúdos na tela, indicando seus tamanhos, espaçamentos, sombras e tudo mais. Eu te convido a aprender maneiras que vão facilitar no desenvolvimento web de sites eficientes e bonitos.
Para começar a dar mais poder para as CSS, criando estilos personalizados, precisamos aprender a utilizar os seletores de id(#) e de class(.) de maneira eficiente. Ao criar nosso conteúdo em HTML, podemos indentificar um determinado elemento único com um id, ou agrupar elementos múltiplos que tenha características semelhantes com um class. Vamos olhar um exemplo simples de documento HTML, com propriedades indentificadoras:

    <h1>Aprenda CSS</h1>
    <h2 class="topico">Estilos Web</h2>
    <p>Lorem ipsum dolor sit amet, consectetur adipisicing elit. Voluptates nostrum ut quo, eaque repudiandae commodi beatae laudantium ducimus eius, est natus, inventore voluptatum excepturi autem eligendi error alias quam sequi.</p>
</body>

Olhando atentamente para o primeiro H1 vimos que ele se diferencia dos demais, pois ele possui um id.
Agora foque sua atenção nas linhas com H2 e perceba que ambos possuem o mesmo class.
Um id vai identificar um elemento único dentro da página atual, essa identificação vai nos permitir criar um estilo especial para um elemento isolado. Já um class vai identificar uma classe à qual um ou mais elementos pertençam, compartilhando características em comum a todos que façam parte desse grupo.
Em um documento HTML só podemos usar um id para um único elemento, o que significa que não podemos ter dois elementos com um mesmo id dentro da mesma página. Porém, podemos atribuir um mesmo class para vários elementos que possuam está mesma característica.
Em seguida, baseado no HTML anterior vamos criar um estilo local criando uma área <style> dentro da seção <head> do documento atual.

        h1{
            font-size: 2em;
            color: darkgreen;

        h2{
            color: green;
        }

o que fizemos foi criar configurações simples de estilo baseadas nos elementos body, H1 e H2 do nosso HTML. Até o momento, não fizemos nenhuma configuração personalizada para nenhum seletor, o resultado é bem previsível.
Perceba no resultado que os dois primeiros títulos possuem apresentação idênticas, mesmo que o primeiro deles possua um id.
Isso aconteceu porque não fizemos nenhuma configuração específica para ele. Não adianta colocar apenas um id ou class em um elemento e não personalizar o resultado visual usando seletores personalizados

        #titulo-principal{

            text-align: center;
        }
        .topico{
            text-align: right;
        }

            text-align: justify;
        }

No código acima, criamos seletores com simbologias novas, isso porque não são seletores para elementos html, e sim seletores para id e class. Na primeira parte criamos um seletor personalizado para o indentificador titulo-principal, que está atribuido ao h1. Você deve lembrar que colocamos o simbolo # antes do id.

Já as linhas seguintes são seletores que receberão declarações para as classes topicos e texto. Todos os seletores personalizado para uma classe são indentificados por um ponto que vem antes do nome da classe.

Quando nós aplicamos configurações personalizadas de id ou de class, também vai existir uma combinação de configurações, como você já deve ter percebido ao analisar o exemplo que apresentamos nas páginas anteriores.

Pseudo-classes e Pseudo-elementos
Uma pseudo-classe CSS é uma palavra-chave adicionada ás declarações de um seletor após dois sinais de dois pontos e especificaram um estado especial de um elemento.
Existem várias pseudo-classes para estilos, podemos citar :hover,:visited,:active,:checked, :empty e :focus.

Já pseudo-elementos CSS é uma palavra-chave adicionada às declrações de um seletor após dois sinais de dois pontos e permitem que você formate um pedaço específico do elemento referenciado. Os principais pseudo-elementos usados nas CSS são ::before,::after,::first line.

Vamos começar criando um exemplo bem simples e bastante usado para exemplificar o uso de pseudo-classes e pseudo-elementos: a personalização de links.

    <h1>Personalizando Links</h1>

    <p>Se quiser conhecer mais sobre padrões, visite o site do <a href="https://www.w3c.br">Escritório Do W3C no Brasil</a></p>
    <p>Para acompanhar os cursos, acesse o <a href="https://www.youtube.com/cursoemvideo/" class="especial">Canal Do Curso Em Video</a></p>

Começando com o corpo do documento, contendo só HTML, vamos criar um texto com um título e três parágrafos, com três links, note que o último link recebeu a atribuição de uma classe específica. O resultado visual é interessante pois por padrão os navegadores mostram links inéditos em azul e os já visitados em violeta. Todos os links aparecem sublinhados por padrão.
Vamos alterar essa apresentação padrão com nossas configurações de estilo. Crie a área <style> dentro do <head. e coloque os seguintes seletores.

        body{
            font: normal 1em Arial, Helvetica, sans-serif;
        }
        a{

            text-decoration: none;
            color: red;
        }
        a:visited{
            color: darkred;
        }
        a:hover{
            text-decoration: underline;
        }

Nas declarações acima, criamos três configurações para os links: a primeira(a) para os links inéditos, colocado o texto em negrito, removendo o sublinhado e colocando os em cor vermelha.

No segundo seletor para links(a:visited) configuramos as âncoras já visitadas (com a pseudo-classe visited) nele, apenas mudamos a cor para vermelho escuro.

Já na terceira declaração(a:hover) fizemos configurações para todos os links, quando passarmos o mouse por cima(pseudo-classe:hover) e o sublinhado volta a aparecer.

 Por fim vamos adicionar algumas configurações relacionadas a classe especial, criada no documento HTML, para o terceiro link.

        .especial:hover{
            color: white;
            background-color: black;
            text-decoration: none;
        }
        .especial:before{
            content: '>';
            font-weight: lighter;
        }
        .especial::after{
            content: '<';
            font-weight: lighter;
        }

Na primeira declaração do código acima(.especial:hover) dizemos que o link de classe especial vai ter letra branca,fundo preto e perderá o sublinhado apenas quando movermos o mouse sobre ele.

Nas proximas declarações(before e after), vamos adicionar um simbolo >antes e depois < usando os pseudo-elementos before e after, respectivamente.

Modelos De Caixa:
O que é uma caixa? De forms simples e objetiva, baseado em um conceito chamado "box model", a grande maioria dos elementos HTML que temos no nosso site são como caixas. Elas são containers que armazenam conteúdos até mesmo de outras caixas.

Anatomia de uma caixa: vamos analisar como uma caixa vai ser apresentada por todos os navegadores. Olhe atentamente o diagrama a seguir, que é exatamente o já citado modelo caixa:
Margin,Outline,Border e Padding.
tudo começa a partir do conteúdo(content), que representamos acima com o bla bla bla...por padrão, toda caixa é composta apenas de conteúdo e não possui padding, nem border, nem outline, e nem margin. uma exceção curiosa é o elemento <body> que já vem com uma margin de 8px.

Todo conteúdo possui uma largura(width) e uma altura(height) e a esse conjunto de propriedades, damos o nome de box-size(tamanho da caixa). O tamanho da caixa não inclui as medidas de padding, border, outline e margin.

Depois do conteúdo e de seu tamanho, vamos nos focar na borda que fica em volta dele. Ela pode ter uma espessura, uma cor e um formato.

Entre a borda e o conteúdo - da borda para dentro - temos o preenchimento (padding) e da borda para fora, temos a margem(margin).

Entre a margem e a borda, podemos determinar o contorno(outline) que é muito pouco utilizado, mas existe. Ele é um traçado visual que podemos criar fora da borde e o cálculo da sua espessura faz parte da margem estabelecida.

Vamos criar um exemplo simples para exemplificar todos esses componentes, configurando as propriedades do modelo de caixa de um título <h1>. Acompanhe o trecho de código a partir das definições de estilo.

    <style>
        h1{
            width: 300px;
            height: 50px;
            background-color: lightgray;
            border-width: 10px;
            border-style: solid;
            border-color: red;
            padding: 20px;
            outline-width: 30px;
            outline-style: solid;
            outline-color: blue;
            margin: 50px;
        }
    </style>
</head>
<body>
    <h1>Exemplo de Caixa</h1>
</body>

Todas configurações serão aplicadas ao elemento <h1>, que é uma caixa e foi criado na tag <h1> do código acima. Já as 2 primeiras linhas do </style> h1{
configuram o size da caixa(largura-width e altura-height) e fará com que ela tenha 300X50 pixels.

as linhas seguintes de Border, configuram uma borda sólida, vermelha e com 10 pixels de espessura.

A linha do padding vai criar um espaço interno de preenchimento ( da borda para dentro) de 20 pixels no elemento e a linha margin vai criar um espaço externo (da borda para fora) de 50 pixels.

As linhas do outline vão usar parte da margem para criar um contorno azul. sólido e com 30 pixels de espessura.
Para calcula o tamanho total de um elemento de tela somes os tamanhos do conteúdo +preenchimento+borda+marge.

Olhando de perto, podemos analisar as medidas configuradas no código apresentado. As medidas de Height e Width(300X50) são medidas apenas pela parte pontilhada do conteúdo.

A border de 10 px ficou em vermelho e o outline de 30px ficou em azul. O padding de 20px fica da borda para dentro e a margin de 50px fica borda para fora.

Sendo assim, a medida total que essa caixa vai ocupar é de 50+10+20+300+20+10+50=460px de largura e 50+10+20+50+20+10+50=210px de altura.

Também podemos decorar as bordas com o border-image importando um arquivo e demais coisas, para isso tambem temos ferramentas como o slice e o repeat slice para cortar e o repeat para repetir.

Existe a nova propriedade box-sizing onde podemos definir que as dimensões height e width não são medidas apenas apartir do conteúdo(content box) e sim pela borda(border-box).

As configurações de borda e contorno também possuem shorthands para simplificar o código anterior. A ordem para as duas configurações é sempre a mesma para as duas shorthands:largura(width);estilo(style) e cor(color).
Ou seja ao invés de:
border-width:10px;
border-style:solid;
border-color:red;

podemos usar

border: 10px solid red;

Preenchimento e Margem Personalizados:
Todo elemento de caixa possui quatro valores para padding e quatro para margin, sempre nesssa ordem: superior(-top), direita(-right), inferior(-bottom), esquerda(-left). Quando colocamos um único valor de dimensão para o preenchimento ou margem, esse mesmo valor é aplicado simetricamente a todas as direções, mas também podemos fazer códigos como:
ao invés disso:
padding-top: 10px;
padding-right: 15px;
padding-bottom: 20px;
padding-left: 25px;
use isso:
padding: 10px 15px 20px 25px

Um recurso que também vai ser muito usado em nossos exercícios é a centralização de blocos, para que isso seja feito, devemos pedir que o navegador calcule automaticamente as margens da esquerda e da direita para que o bloco seja colocado no meio do navegador, independente do tamanho da janela.

Para centralizar uma caixa, usa a seguinte declaração no seu seletor:
Margin:auto;

Tipos de Caixa

Dependendo do comportamento da caixa, podemos classificar um elemento em uma de duas categorias

Caixa do tipo block-level

um elemento dito block-level sempre vai se iniciar em uma nova linha e vai ocupar a largura total do elemento onde ele está contido. Se não estiver contido em nenhuma outra caixa, ele vai ocupar 100% da largura do <body>.

O elemento block level mais conhecido é o <div> e suas variações semânticas modernas do html5, xomo <main>, <selection>,<aside> etc...

Caixa do tipo Inline-level

Um elemento do tipo inline-level não vai começar em uma nova linha, e sim no ponto exato onde foram definidos, e a largura dele vai ocupar apenas o tamanho relativo ao seu conteúdo.

Text-align serve para alinhar o texto da forma que o programador quiser como por exemplo torna-lo centralizado(center) justificado(justify) e etc..

Tipografia

Uma boa forma de transmitir intenções  e emoções, assim como cores e imagens a escrita é uma forma importante de passar coisas a outras pessoas.

Anatomia dos tipos, altura-x baseada nos tamnhos da letra x minúscula para usar de escala para as outras letras minúsculas, Altura das maiúsculas é separada e não tem escala, ascendente é o vazamento das letras minúsculas para cima além da altura-x, descendente é o vazamento das letras para baixo. Somando todas as alturas é a altura do corpo.

Serifas são os "pézinhos" das letras de algumas fontes, serifa facilita a leitura das palavras, seu cérebro não lê as letras individualmente mas sim a palavra toda.
Um conjunto de glifos se chama família, e tem fontes que tem familias tipograficas como light e bold.
Categorias De Fonte
Fontes serifadas são as com serifas.
Sans-serif são fontes sem serifa.
Monoespaçadas, pode ter serifas ou não, mas sua característica é todas as letras ter o mesmo tamnho.
Handwriting, simula a caligrafia a mão.
Display, fontes que não se encaixam em nenhuma das anteriores normalmente fontes simulando coisas também chamadas de fontes comemorativas.

Grouping Tags e Semantic Tags

A linguagem HTML padão tinha apenas duas de agrupamento genérico: a <div> e a <span>. A diferença básica entre elas é que a primeira é um elemento agrupador do tipo block-level e o segundo é inline-level.No mais, eles agem exatamente da mesma maneira, servindo para juntar vários outros HTML.

Com o surgimento da HTML5, surgiram as tags semânticas de agrupamento. Isso não significa que as <div> e <span>(agora chamadas de não-semanticas) deixaram de existir ou ficaram obsoletas, mas seu uso agora faz menos sentido, pois temos tags para dividir as partes dos nossos documentos HTML.

Vamos compreender a partir de agora os principais agregadores semânticos da HTML5.

Podemos traçar uma linha ao redor da caixa e esta linha vamos chamar de border, e podemos usar um padding para ampliar um espaço entre o conteúdo e a borda e podemos também criar um espaço entre duas bordas que é o margin também podemos criar um traço entre a borda e a margin chamado outline.

Temos dois tipos de caixa o box-level e o inline-level, box-level sempre se inicia em uma linha nova e sempre ocupa a largura total do navegador.
E um inline-level ocupa o espaço restante da linha e também não pula linha se ele acabar e ainda haver espaço ele contínua o conteúdo após a caixa.
Box Level(<div>,<h1--h6>,<p>,<main>,<header>,<nav>,<article>,<aside>,<footer>,<form> e <video>) Inline Level(<span>,<a>,<code>,<small>,<strong>,<em>,<sup--sub>,<label>,<button>,<input> e <select>).

A ordem para alteração de padding, margin e etc... por meio de shorthands é cima, direita, baixo e esquerda.

Podemos alterar as medidas de qualquer caixa.
Todo elemento que quisermos no meio da tela usamos margin auto.
Podemos também centralizar apenas a parte de cima, de baixo da direita ou esquerda trocando seu tamanho para auto.
Podemos alterar caixas que de forma default seriam block para inline e vice versa manualmente por meio das CSS.

Podemos colocar espaçamento entre as caixas, alterar suas cores individuais espaçamento margem e etc...

1.Deslocamento horizontal (h-offset): quanto a sombra vai andar para o lado direito(valores negativos causam deslocamento para a esquerda).
2.Deslocamento Vertica (v-offset): quanto a sombra vai andar para baixo (valores negativos causam deslocamento para cima)
3.Embaçamento (blur): quanto a sombra vai se espalhar pelo fundo.
4.Cor(color): cor da sombra. É possível usar transparência.

Para criarmos variáveis para nossas configurações, devemos definir uma área de definições dentro do seu estilo para pseudo-classe chamada:root, que definem as configurações para a raiz de uma árvore, que vai servir para o documento inteiro.

A partir de agora, definir cores e fontes em nossos elementos html ficará mais fácil e personalizavel, utilizando a função var().

        body{

Flex Direction

Existem 4 configurações permitidas para containers de flex-direction a configuração padrão é flex-direction: row; ela faz uma direção de padrão em linha da esquerda para direita, caso usar flex-direction: row-reverse; ela faz uma direção de linha da direita para esquerda assim como a escrita oriental, para dispositivos verticais usamos flex-direction: column; em coluna ele é verticalmente de cima para baixo assim como o row temos a versão reverse que seria de baixo para cima, quando escolhemos criamos os eixos, o eixo principal é main-axis ele fera dois pontos um inicial e um final, chamamos eles de main-start e o main-end, também temos o eixo transversal ou cross-axis que também tem pontos os quais chamamos de cross-start e cross-end, no flex-direction: row; o main-axis é da esquerda para a direita e o cross-axis de cima para baixo, em caso de flex-direction: row-reverse; o main-axis se inverte sendo da direita para esquerda porém o cross-axis não tem alteração. 
Para flex-direction: column; o main-axis fica de cima para baixo já o cross-axis fica da esquerda para a direita, e em caso de reverse o main-axis fica de baixo para cima e o cross-axis não sofre alteração, o main-axis sempre seguirá a direção do objeto ou melhor dizendo o container será direcionada pelo main-axis.

Flex-Wrap(encapsulamento)

Por padrão o flex-wrap está configurado como flex-wrap: nowrap; ou seja não encapsule, o encolhimento dos itens dentro de um flex-box depende da capacidade de encolhimento dele, o tamanho de um bloco depende do conteúdo que tem nele, flex-wrap: wrap;  ao diminuir demais o conteúdo ele irá quebrar no sentido do cross-axis,  podemos também usar o flex-wrap: wreap-reverse; o que é? quando ele quebrar será no sentido oposto do eixo cross-axis.

Simplificação Do Flex

Podemos simplificar tudo usando flex-flow(flex-direction+flex-wrap)a ordem é como ao lado primeiro Direction dps wrap.

flex: auto; faz com que não haja espaço em branco dentro do contêiner.

Justify-Content

Justify-content ele vai fazer o alinhamento em relação ao main-axis, o valor que geralmente usamos é o justify-content: flex-start; ele está relacionado ao main-start, o primeiro item vai ficar grudado no main-start caso exista espaço livre sempre vai ficar junto do main-end,justify-content: flex-end; ele está relacionado ao main-end, o último item vai ficar grudado no main-end caso exista espaço livre sempre vai ficar junto do main-start, temos também o justify-content: center; que irá centralizar os itens no main-axis e o espaços em branco serão distribuídos de forma igual entre o main-start e o main-end, alinhamentos de espaçamento, justify-conten: space-between; ele irá colocar o primeiro item no main-start e o último item no main-end todos os outros itens vão estar no centro com o espaçamento distribuído por igual, temos também jutify-content: space-evenly; não irá grudar o primeiro e o último elemento nas extremidades ele vai colocar os elementos dentro do container para que antes e depois independente de ser o primeiro ou o último tenha espaços de forma igual, justify-content: space-around; ele não gruda os elementos nas extremidades e divide o espaço pela quantidade de elementos reservando espaços de tamanhos iguais e dentro desses espaços ele irá centralizar o conteúdo tendo espaço atras e a frente do item, sendo assim tem espaços duplos entre dois elementos o fim do espaço anterior e o inicio do espaço do elemento posterior.

Align Itens

align-itens ele vai fazer o alinhamento em relação ao cross-axis, por padrão o align-itens tem o valor stretch(esticar), existe também o flex-start que alinha os itens com o cross-start, obviamente também existe o flex-end que cola os itens ao cross-end, exite também o center para centralizar os itens na área central do cross-axis porém, não exite os spaces. 

Resumindo um pouco está aula o justify-content alinha junta ao main-axis e o align-itens alinha junto ao cross-axis.
